# BattleTech CYOA

A character and story-planning aid for writers of BattleTech self-insert fiction.

Choose an Era and starting Location, then build a character and copy the story brief. The writer controls the plot, historical divergence and story duration. Points and sample choices remain illustrative.

Development version 0.04. Version 1 is reserved for the completed initial release.

The application runs in the browser. Maps, emblems and application data are included. Source and artwork credits appear inside the application. Saved drafts stay in the visitor's browser and do not transfer automatically between devices or website addresses.

This repository contains the public deployment copy. The managed authoring workspace and research archive remain separate.
